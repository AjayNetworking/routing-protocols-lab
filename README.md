\# Routing Protocols Lab



\## Overview



This project is a practical study of computer network routing protocols and routing concepts.



The goal is to understand how routers learn, select, and maintain routes between different networks.



\## Topics Covered



\- Static Routing

\- Default Routing

\- RIPv2

\- OSPF

\- EIGRP

\- Routing Tables

\- Administrative Distance

\- Routing Metrics

\- Route Selection

\- Convergence

\- Routing Troubleshooting



\## Network Concepts



\### Static Routing



Static routes are manually configured by a network administrator.



\### RIPv2



RIPv2 is a distance-vector routing protocol that uses hop count as its routing metric.



\### OSPF



OSPF is a link-state routing protocol that uses the Shortest Path First algorithm to calculate routes.



\### EIGRP



EIGRP is a Cisco-developed routing protocol that uses multiple parameters to calculate the best path.
